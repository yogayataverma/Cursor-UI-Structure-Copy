# Cursor-Inspired Landing Page

A desktop-first static recreation of the Cursor website structure using only HTML and CSS (no JavaScript, no Tailwind). The focus is on matching layout, hierarchy, typography, and color palette.

## Screenshot
- [Homepage preview](https://github.com/yogayataverma/Cursor-UI-Structure-Copy/blob/master/Image1.png)

## Included Sections
- Top navigation bar with logo, links, and CTA
- Hero with headline, description, CTA buttons, and product mock
- Trusted-by logos row
- Three alternating feature blocks (text + visual)
- Feature cards grid
- Testimonials
- Use cases / stories grid
- Changelog list
- Team / About block
- Final CTA
- Footer with multi-column links and company info

## Fonts
- **Sora** for headings and logo wordmark
- **Inter** for body copy and UI text

Fonts are loaded via Google Fonts in `index.html`.

## Colors
- Background: `#0b0f19`
- Surface / cards: `#0f1520`, `#131a26`
- Text: `#e9edf5`, muted text `#9fb0c9`
- Borders: `#1f2533`
- Accents: `#8b7bff`, `#64d4ff`, `#5be7a9`

## How to Run
Open `index.html` in a desktop browser. The page is desktop-first; no responsiveness is required.

## Notes
- Images use simple gradients and one Unsplash photo to approximate the Cursor visuals. You can replace them with official assets if available.
- No JavaScript, animations, or interactivity have been added to stay within the assignment constraints.
